# Build a Planetary System

An interactive game that walks through planetary system formation: molecular cloud, protostar, protoplanetary disk, planets. Your starting choices (cloud mass, temperature, density, spin, and ingredients) change the final system.

Physics follows Chapter 15 of *Fundamentals of Planetary Science* (Lissauer & de Pater): Jeans mass, free-fall time, centrifugal radius, disk torques (viscous, magnetic, gravitational), condensation and the snow line, isolation mass, and core-nucleated giant planet formation. The SED panel uses simple blackbody curves; see the Disk Detective post on SEDs: https://blog.diskdetective.org/2014/02/01/spectral-energy-distributions-seds/

The model is simplified for teaching and is not a research simulation.

## Run it
Open `index.html` in a browser. It is a single file with no build step. Google Fonts load from the web, with fallbacks if offline.

## Host on GitHub Pages
Push `index.html` to a repo, then go to Settings > Pages and choose the main branch, root folder.
